# 📊 주문 현황 및 매출 분석 대시보드

기간별 주문 엑셀을 시각화하여 매출 추이와 인기 상품, 주문 패턴을 한눈에 파악할 수 있는
대시보드입니다.

---

## 🎯 주요 기능

* 일별/월별 **매출 추이 차트**를 제공합니다.
* **인기 상품 Top 10**을 자동으로 집계합니다.
* **시간대별 주문 분포** 분석 차트를 제공합니다.

## 💻 사용 방법

1. 분석하고 싶은 **기간별 주문 엑셀**을 업로드합니다.
2. 자동으로 매출 추이, 인기 상품, 시간대별 분포 차트가 생성됩니다.
3. 필요한 기간/조건으로 필터링하여 확인합니다.

## 🛠️ 기술 스택

* **Language**: Python
* **Web Framework**: Streamlit
* **Data Processing**: Pandas, OpenPyXL

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```
